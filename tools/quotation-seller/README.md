# ออกใบเสนอราคา SUNFORD

ลูกค้าเปิดหน้า `/service/quotation` กรอกข้อมูล เลือกสินค้า แล้วส่งไฟล์ PDF ที่ดาวน์โหลดให้ผู้ขาย

PDF ของลูกค้ามีเลข 8 หลัก วันที่ออกตามเวลาไทย วันหมดอายุอีก 14 วัน และผู้ติดต่อ กำไลพลอย ศรีพุ่มไข่ ผู้ขายเปิด `SUNFORD-seller.html` ด้วย Chrome หรือ Edge เลือก PDF ใบนี้ กรอกเงื่อนไขของใบ แนบภาพลายเซ็นและ QR แล้วกดดาวน์โหลด ทั้งลูกค้าและผู้ขายได้ไฟล์ชื่อ `SUNFORD.pdf` เครื่องมือนี้ทำงานออฟไลน์ หากได้รับ PDF รุ่นเดิมที่ยังไม่มีเลข ให้นำไปออกเลขผ่านหน้าใบเสนอราคาก่อน

ระบบจริงใช้ตาราง `quotation_issues` ใน PostgreSQL ของเว็บไซต์ผ่าน `DATABASE_URL` และ migration ของโปรเจกต์ บนเครื่องพัฒนาที่ไม่มี URL นี้ ทะเบียนจะอยู่ที่ `.local/quotation-issues.sqlite` ต้องเก็บทะเบียนเพื่อให้เลขต่อจากครั้งก่อน

สร้างเครื่องมือสำหรับส่งให้พนักงานจากรากโปรเจกต์ด้วย `node tools/quotation-seller/build.mjs` แล้วนำ `output/quotation/SUNFORD-seller.html` ไปเปิดหรือคัดลอกไปเครื่องผู้ขาย

สำหรับใบที่มีหลายหน้า ให้ใช้เครื่องมือผู้ขายรุ่นนี้แทนไฟล์เดิม เพื่อให้ลายเซ็นและ QR อยู่ตรงกับส่วนรับรองหลังรายการสุดท้าย เครื่องมือรุ่นนี้ยังเปิดใบที่ออกเลขแล้วในรูปแบบเดิมได้

รัน `node tools/quotation-seller/verify.mjs "<พาธ PDF ต้นฉบับ>"` หลังสร้างเครื่องมือ เพื่อตรวจข้อมูลตัวอย่างผ่าน Chrome และเปรียบเทียบ PDF ทั้งสองด้วย pdftoppm ผลที่ได้อยู่ใน `output/quotation/` ภาพลายเซ็นและ QR ที่ใช้ทดสอบอ่านจากไฟล์ตัวอย่างเฉพาะตอนตรวจเทียบ
