# Sunford contact mascot

The mascot replaces the old chat launcher across all site pages. Clicking the mascot or the repeating “ติดต่อสอบถามได้ที่นี่เลย” invitation opens the contact menu. The invitation never navigates to Sunford Shop; only the shop row opens that destination. Dragging does not open the contact panel.

The compact menu is 248 CSS pixels wide and contains the four telephone, LINE, Messenger and Sunford Shop rows, without a heading. On desktop it closes when the mouse leaves the combined pet/menu region, with 10 pixels of tolerance and a bridge across their gap. Touch lifting does not dismiss it; tapping the mascot again, tapping outside or pressing Escape closes the menu.

- 64 walking poses: 32 right-facing and 32 left-facing, stored in eight local WebP sheets with eight poses each.
- Approximate total walking-image payload: 2.77 MB; the sharp front/idle sheet is 240 KB. No third-party animation service.
- Sheets decode once before automatic walking starts; an asset failure leaves the front pose and contact button usable.
- Slow autonomous speed: 8 CSS pixels per second; 32 poses over 3.2 seconds per directional cycle.
- Pointer-captured dragging works with mouse or touch, clamps to the viewport and suppresses accidental click activation after a drag.
- Feet advance with the distance and direction of pointer movement, and remain still while holding without moving.
- Pose layout metadata aligns the head, size and baseline on a retained 2D canvas. The source artwork is not mirrored.
- All 64 normalized poses are prepared in a device-resolution canvas atlas before walking starts. Each step displays exactly one fully opaque pose; there is no cross-fading or duplicated-foot blur.
- Pose 31 wraps directly to pose 0 on the same retained drawing surface. No image elements are removed or reloaded between steps.
- Canvas content remains visible during hover, pause and contact-menu use. Destination images are validated before repainting; an image failure retains the last valid pose.
- Hover and keyboard focus stop autonomous movement. Pause and reduced motion are supported. Hidden tabs stop the animation loop.
- The shop invitation repeats every 10 seconds, visible for about 5 seconds. Contact menu, bubble and pet remain bounded to the screen.

## Image generation

Created with the built-in imagegen tool, using the existing high-resolution child and actual ACS-30-JC21 product as references. Each sheet is generated separately to preserve detail; the final eight sheets replace the low-resolution combined 8×8 attempts. Original generation outputs remain in the imagegen output folder. WebP encoding preserves alpha.
