# ย้ายติดต่อเราเข้า Sidebar ของบริการ

เจ้าของอนุมัติวันที่ 24 พ.ย. 2026 ให้ย้ายหน้าติดต่อและเปลี่ยนปลายทางลิงก์ทั่วเว็บ โดยคงหน้าตาและการใช้งานของการ์ดเดิม

- เพิ่ม “ติดต่อเรา” ต่อจากบริการเดิมทั้งห้าใน `/service` กดจาก Sidebar ได้ในเอกสารเดิม และเปิดตรงด้วย `/service?section=contact` ส่วน `/contact-us` ส่งต่อด้วย HTTP 307
- ย้ายการ์ด Facebook, LINE, โทรศัพท์, อีเมล และแผนที่ดาวเทียมสำนักงานบางเลน โดยใช้สี ไอคอน ข้อความ และปลายทางเดิม ปรับกริดและขนาดตัวอักษรตามพื้นที่ข้าง Sidebar แผนที่ฝังเริ่มโหลดเมื่อเปิดแท็บและเข้าใกล้วิวพอร์ต ลิงก์ Google Maps ใช้ได้เมื่อปิด JavaScript
- อัปเดตลิงก์ Navbar, Footer, หน้าสินค้า, คู่มือ, เนื้อหาที่นำเข้า และผลค้นหา เก็บเส้นทางเดิมในข้อมูลต้นทางเพื่ออ้างอิง ย้อนกลับได้โดยคืนชุดการเปลี่ยน route และลิงก์พร้อมกัน ข้อมูลและ API ใช้สัญญาเดิม

## ผลตรวจ

- Chrome ผ่านชุดบริการและติดต่อ 18 เคสที่ `320–1440px` รวมคีย์บอร์ด, URL เดิม, แท็บผ่าน Navbar/Footer, Back/Forward และลิงก์แบบปิด JavaScript ชุดติดต่อและคู่มือรอบสุดท้ายผ่าน 20 เคส และทางเข้าจาก Hero ผ่าน 5 เคส
- Chrome เปิดแผนที่ดาวเทียมจริงได้ HTTP 200 ผลค้นหา “ติดต่อ Sunford” ชี้มาที่แท็บติดต่อ การตรวจ Back/Forward จาก Hero เปิดแท็บถูกต้อง ชุดเทสต์ประวัติ Hero พบคำเตือน hydration จาก `HomeMotion` บนหน้าแรกก่อนกดลิงก์
- Catalog ผ่าน 232 เคส ตรวจ URL ภายในและความถูกต้องของเนื้อหานำเข้าผ่าน TypeScript และ ESLint ผ่าน Production build ด้วย Webpack บน Node 24 สร้างครบ 701 หน้า ส่วน Turbopack รุ่นเดียวกันหยุดก่อนเชื่อมต่อกับโปรเซสย่อยของงาน CSS บน Windows
