# Navbar และ Footer ใช้ข้อมูลและระยะร่วมกัน

เจ้าของอนุมัติแผนวันที่ 24 พ.ย. 2026 ขอบเขตครอบคลุม Layout สาธารณะ หน้า 404 และลิงก์เมนูทั้งสองส่วน เครื่องมือตรวจ Warehouse `/warehouse-products-test` อยู่นอก Layout นี้

## ผลตรวจเดิมและการแก้ไข

- หน้าแรกและหน้าในใช้ Navbar คนละคอมโพเนนต์ แผงเมนูเครื่องชั่งที่จอ `1440px` เริ่มที่ `224px` และ `208px` ตามลำดับ ส่วนหน้าภาพรวมสินค้ามี Footer แยกอีกชุดหนึ่ง ที่จอเดียวกันส่วนหลักของ Footer สูงประมาณ `484–496px` แม้ padding บนล่างเท่ากัน
- ให้ `SiteFrame` ใช้ Navbar และ Footer ชุดเดียวกัน แยกแถบชวนติดต่อก่อน Footer ตามเงื่อนไขเดิม และรวมค่ากรอบและระยะใน CSS กลาง กำหนดสัดส่วนโลโก้กับความหนาขอบแถบนโยบายให้ตรงกันทุกธีม
- ใช้ชื่อกลางตามปลายทาง ลบลิงก์ติดต่อซ้ำ 3 รายการในเมนูย่อยของโครงสร้างแท่นชั่ง อุปกรณ์เสริม และจัดสเปค รักษา query และ hash ของลิงก์ที่เปิดตัวกรองหรือเลื่อนไปยังส่วนที่เกี่ยวข้อง

## หลักฐานตรวจรับ

- Chrome ตรวจ 27 เส้นทางสาธารณะ ที่ `390 / 834 / 1023 / 1024 / 1440px` รวม 135 การวัด เทียบข้อความ ลำดับลิงก์ และกรอบของ Navbar และ Footer ที่มองเห็น ผลต่างของกรอบไม่เกิน `1px` ตามเกณฑ์
- ทดสอบเมนูย่อยทั้ง 8 ชุดจากหน้าแรก หน้าผลิตภัณฑ์ และหน้าติดต่อที่ `390 / 834 / 1440px` เทียบตำแหน่ง ขนาด คอลัมน์ และลิงก์ นอกจากนี้ตรวจเส้นทางของเมนูหลักและความถูกต้องของ hash เปิดตัวกรอง ค้นหา โฟกัสคีย์บอร์ด การกลับด้านบน และ Back/Forward ด้วย Chrome
- ชุดทดสอบ Chrome รอบหลักผ่าน 46 เคส ทดสอบการเปลี่ยนธีมและ Footer ที่ `320 / 390 / 834 / 1440px` ผ่าน 6 เคส และรันซ้ำกรณีปลายทางกับโฟกัสโลโก้ผ่าน 2 เคส ชุดแค็ตตาล็อกผ่าน 232 เคส
- `typecheck`, `lint` และ `git diff --check` ผ่าน Production build ล่าสุดบน Node 24 สร้างครบ `702/702` หน้า

หากต้องย้อนกลับ ให้คืนชุด diff ของ Navbar, Footer, ตารางชื่อเมนู และเทสต์ที่เกี่ยวข้องพร้อมกัน งานนี้ไม่มีการเปลี่ยนฐานข้อมูล API หรือขั้นตอนปล่อย Production
