# Hover lift แทนเส้นใต้เมื่อชี้

เจ้าของขอเปลี่ยนทั่วโปรเจกต์และยืนยันว่าเป็น hover lift วันที่ 26 พ.ย. 2026 ขอบเขตคือกฎที่เพิ่มเส้นใต้เมื่อชี้ใน CSS ส่วนกลางและ CSS Modules ของ Footer หน้าดาวน์โหลด แค็ตตาล็อก หน้าสินค้า และนโยบายรับประกัน

ใช้ `--text-hover-lift` ใน `src/styles/base.css` สำหรับระยะ `2px` บนอุปกรณ์ชี้ที่รองรับ hover แบบละเอียดและเปิดการเคลื่อนไหว ใช้เวลา `250ms` จาก transition ลิงก์ของ SUNFORD กับเฉพาะองค์ประกอบที่ปรับ แยกกฎ hover ออกจากกฎพื้นฐาน โฟกัส และสถานะเลือก ย้อนกลับโดยคืนเฉพาะตัวแปรและกฎ hover รอบนี้

- ตรวจ CSS 64 ไฟล์แล้วไม่พบกฎที่เพิ่มเส้นใต้เมื่อ hover
- Chrome ที่ `1440px` ตรวจหน้าดาวน์โหลด Footer สารบัญนโยบาย ลิงก์กลับหน้าสินค้า ชื่อสินค้าในราง และลิงก์ดาวน์โหลดจากหน้า POS
- Chrome ที่ `768px` ตรวจหน้าดาวน์โหลด สารบัญนโยบาย และโฟกัสคีย์บอร์ด จอสัมผัสที่ `390px` ตรวจว่าลิงก์เปิดได้โดยไม่ยก
- Playwright ผ่าน 3 เคสครอบคลุม hover, Reduce Motion และหน้าดาวน์โหลดสองขนาด Typecheck และ Prettier ของไฟล์ที่แก้ผ่าน
