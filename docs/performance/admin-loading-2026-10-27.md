# ผลการปรับความเร็วแอดมิน — 27 ตุลาคม 2026

วัดด้วย session แอดมินจริงและฐานข้อมูลเดิม บน Next.js dev ที่ localhost:3000 ผ่าน streaming proxy ภายในเครื่อง วัดตั้งแต่เริ่มส่ง HTTP GET ถึงรับ HTML/RSC stream ครบ ไม่รวมเวลาของเครื่องมือควบคุม browser และไม่ใช่เวลา paint หรือการวัดบน production

อุ่นทั้ง 7 หน้าก่อนวัดแต่ละชุด ไม่รวม warm-up ในผล เก็บก่อนแก้ 2 ชุด ชุดละ 5 รอบ และหลังโค้ดสุดท้าย 10 รอบ รวม 140 requests ที่ตอบ 200 ทั้งหมด เรียงเส้นทางแบบเดิมทุกครั้ง ไม่มีการแก้ข้อมูลสินค้า เนื้อหา บัญชี หรือ schema ระหว่างทดสอบ ใช้ค่ามัธยฐาน (median) เพื่อลดผลจากค่าที่กระโดดสูง

## สิ่งที่เปลี่ยน

- ใช้ React.cache รวมผล getUser และตรวจสิทธิ์แอดมินภายใน server render เดียว โดย request ถัดไปตรวจใหม่ ไม่มี persistent cache ของสิทธิ์หรือ session
- Server Action สำหรับเปิดรายละเอียดตรวจสิทธิ์หนึ่งครั้ง แล้วส่ง session ที่ตรวจแล้วให้ฟังก์ชันภายในที่ไม่ใช่ Server Action ส่วนการเรียกฟังก์ชันอ่านโดยตรงยังตรวจสิทธิ์เอง
- ฟอร์มตั้งค่าไม่โหลดสินค้าถ้าไม่มีช่องเลือกสินค้า ช่องเลือกสินค้าโหลดเฉพาะ id/name/published และโหลดรายการหมวดหมู่เฉพาะฟอร์มหมวดหมู่
- หน้าหมวดหมู่อ่านเฉพาะข้อมูลจำแนกหมวดหมู่ 4 fields เพื่อคงกติกา legacy/custom category และนับ draft ตามเดิม โดยไม่โหลดรายละเอียดสินค้าทั้งรายการ
- ตารางสินค้า query และส่งเฉพาะ 9 fields ที่แสดง/ใช้จัดการ พร้อม fields ภายในสำหรับแก้ค่า legacy ฟอร์มรายละเอียดสินค้าโหลดข้อมูลเต็มเมื่อเปิดตามเดิม
- ปิด prefetch ของลิงก์ที่เปิดผ่านแผงข้าง เพราะการกดปกติโหลดผ่าน Server Action อยู่แล้ว

## การตรวจสอบ

- ชุดทดสอบ server loading 6 รายการ: รวม Auth ต่อ render, ไม่แชร์สิทธิ์ข้าม request, ปฏิเสธ anonymous/revoked/non-admin, ไม่ query เกินจำเป็น, ยอดหมวดหมู่และข้อมูลตารางคงเดิม
- Production build และ TypeScript ผ่าน; scoped ESLint ผ่าน
- Browser fixture ผ่าน 12 รายการ และตรวจ anonymous routes บนเซิร์ฟเวอร์จริงผ่านเมื่อรันแยกหลัง build เสร็จ (รอบแรก timeout ระหว่าง build); ตรวจยอดหมวดหมู่จริงตรงเดิมและเปิดฟอร์มสินค้าเดิมผ่าน Server Action ได้โดยไม่บันทึก
- รันชุด regression ใหม่ซ้ำได้ด้วย `node --conditions=react-server --test tests/admin/data-loading.test.mjs`
- ชุด catalog เดิมผ่าน 17/18 รายการ อีกหนึ่งรายการคาดหวัง rls1100.png แต่ค่า default ใน HEAD ใช้ rls1100-spotlight.png อยู่แล้ว ไฟล์ default และ test นี้ไม่ได้เปลี่ยนในการปรับ performance
