# ผลแก้บั๊กแถวชื่อรุ่น Carousel

ตรวจล่าสุด: 11 พฤศจิกายน 2026

แก้แถวชื่อรุ่นที่ล้นออกนอกภาพ Carousel แล้ว โดยจำกัดความกว้างตาม gutter เดิม ชื่อรุ่นไม่ถูกบีบหรือหักหลายบรรทัด เลื่อนแถวในแนวนอนได้เมื่อมีชื่อเกินพื้นที่ และเลื่อนตามรุ่นที่เลือกโดยไม่ทำให้หน้าเลื่อนขึ้นลง แยก gesture ของแถวชื่อออกจากการเปลี่ยนสินค้าหลัก

## หลักฐาน

- ก่อนแก้ หมวดที่มี 41 รุ่นสร้างแถวกว้างประมาณ 1,992px และเริ่ม x=-682px บนจอ 1440px การทดสอบ browser ล้มเหลวตรงขอบเขตนี้จริง
- หลังแก้ การทดสอบแถวชื่อใหม่ 6 กรณีผ่านกับข้อมูล 41 รุ่น รวมการเลื่อนไปเลือกรุ่นท้ายและ native touch โดยไม่เปลี่ยนสินค้าหลักโดยไม่ตั้งใจ
- เวอร์ชันล่าสุดมีงานที่ผู้ใช้อนุมัติภายหลังให้คืน Carousel เป็น 36 รุ่นคัดสรร แบ่ง 12 กลุ่ม กลุ่มละ 3 รุ่น พร้อมซ่อน scrollbar จึงรักษาทั้งสองข้อนี้ไว้ ไม่มีการนำสินค้าทั้งคลังกลับเข้า Carousel
- ตรวจ source ปัจจุบันบน `http://localhost:3000`: **Browser 12/12**, **catalog tests 137/137**, TypeScript และ scoped ESLint ผ่าน
- ครอบคลุมความกว้าง **320, 390, 834, 1440 และ 1887px** รวมการเลือกชื่อ ปุ่มก่อน/ถัดไป หมวดสินค้า swipe รูป/พื้นหลัง wheel เปิดรายละเอียดและกลับสู่ Carousel
- ภาพล่าสุดที่ 390/1887px ตรวจด้วยตาแล้ว และ browser บันทึก **0 console/page errors** แถวชื่ออยู่ระหว่าง 20–370px บนมือถือ และ 353.5–1533.5px บนจอ 1887px

การทดสอบรวมรอบก่อนถูกหยุดจากภายนอกหลังผ่าน 9 กรณี จึงทดสอบ source ล่าสุดใหม่จนจบครบ 12 กรณี ไม่ใช้รอบที่ถูกหยุดเป็นหลักฐานว่าผ่านทั้งหมด

## ขอบเขต

แก้เฉพาะ selector ของ Carousel ไม่เปลี่ยนรูปสินค้า ตำแหน่งภาพ transition หรือ shared style การตรวจรอบสุดท้ายไม่มีการแก้ application source เพิ่ม รักษางานล่าสุดของผู้ใช้ไว้ dev server Node24 / Turbopack เปิดอยู่ที่ [หน้าสินค้า](http://localhost:3000/products) ไม่ได้ deploy จากงานนี้
