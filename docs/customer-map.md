# แผนที่ลูกค้า Sunford

กด **ดูแผนที่ลูกค้า** ในส่วน “ครอบคลุมทั่วประเทศ” ที่ท้ายเว็บไซต์

- มุมกว้างแสดงจังหวัด เมื่อซูมใกล้ขึ้นจะแสดงอำเภอ/เขตอัตโนมัติ
- การซูมอัตโนมัติหยุดที่ระดับอำเภอ/เขต
- คลิกอำเภอหรือเลือกจากช่องรายการ เพื่อดูตำบล/แขวงเฉพาะอำเภอนั้น
- คลิกตำบลเพื่อขยายพื้นที่และดูจำนวนรายชื่อ หรือใช้ช่องค้นหา
- กด “กลับไปดูทุกอำเภอ” เพื่อกลับระดับอำเภอ
- ใช้ล้อเมาส์ สองนิ้วบนมือถือ ปุ่ม +/− หรือลูกศรบนแป้นพิมพ์เพื่อเลื่อนและซูม

## ข้อมูลจาก Excel

ใช้ไฟล์ **สัดส่วนลูกค้ารายจังหวัดและตำบล_2569-10-27.xlsx** ข้อมูล ณ 27 ตุลาคม 2569 เวลา 11:21 น. กรุงเทพฯ

| รายการ                              | จำนวนรายชื่อ |
| ----------------------------------- | -----------: |
| ทั้งทะเบียน                         |      125,804 |
| ระบุจังหวัดได้                      |       97,758 |
| ยังไม่ทราบจังหวัด                   |       28,003 |
| ต่างประเทศ                          |           43 |
| ระบุได้ถึงตำบลและรวมเป็นยอดอำเภอได้ |       85,000 |
| ทราบจังหวัดแต่ยังไม่ทราบตำบล        |       12,758 |

หน่วยคือ **รายชื่อในทะเบียน อาจซ้ำบุคคลได้** ตามหมายเหตุใน Excel ไม่ใช่จำนวนบุคคลที่ไม่ซ้ำกัน และไม่ใช่ยอดเฉพาะลูกค้าที่กำลังใช้งาน

ยอดจังหวัดใช้ยอดจากชีต “สรุปจังหวัด” ส่วนยอดอำเภอรวมจากตำบลในชีต “ตำบลทุกจังหวัด” จึงไม่รวม 12,758 รายชื่อที่ยังไม่ทราบตำบล ไม่กระจายยอดดังกล่าวไปยังอำเภอโดยการคาดเดา

นำเข้าครบ 77 จังหวัด 928 อำเภอ/เขต และ 7,440 ตำบล/แขวง รวมแถวที่มี 0 รายชื่อไว้ด้วย พื้นที่ที่ไม่มีข้อมูลใช้ `null` แยกจากศูนย์ที่ยืนยันแล้ว

## ไฟล์ที่อ่านและตรวจสอบได้

| ไฟล์                                                  | ใช้ทำอะไร                                                                                   |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `data/customer-map/customer-counts-readable.json`     | ชื่อจังหวัด อำเภอ ตำบล จำนวนรายชื่อ รหัสพื้นที่ สถานะขอบเขต และแถวต้นทาง ใช้ค้นหาภาษาไทยได้ |
| `data/customer-map/source-aggregates.json`            | ข้อมูลที่อ่านจาก Excel โดยเก็บชื่อและยอดต้นฉบับไว้                                          |
| `data/customer-map/import-report.json`                | ผลตรวจยอดรวม รายการที่ไม่มีขอบเขตตรงกัน และการปรับชื่อที่ตรวจสอบด้วยรหัส                    |
| `src/features/customer-map/data/customer-counts.json` | ยอดรวมที่เว็บไซต์ใช้งาน แยกตามรหัสพื้นที่                                                   |
| `public/maps/thailand/source.json`                    | ที่มา เวอร์ชัน วันอ้างอิง และ SHA-256 ของไฟล์ขอบเขต                                         |

มี 16 พื้นที่ รวม 844 รายชื่อ ที่ยังไม่มีรูปขอบเขตตรงกับข้อมูลอ้างอิง ยังค้นหา เลือก และดูยอดได้ครบในรายการ พร้อมข้อความแจ้งบนแผนที่ ไม่วาดพิกัดหรือขอบเขตสมมติ รายละเอียดทั้งหมดอยู่ใน `import-report.json`

## โครงสร้างโค้ด

- `components/customer-coverage.tsx`: ปุ่มเปิดจาก footer และโหลดส่วนแผนที่เมื่อใช้งาน
- `components/customer-map-dialog.tsx`: รายการพื้นที่ การค้นหา ยอดรวม และลำดับจังหวัด/อำเภอ/ตำบล
- `components/map-canvas.tsx`: วาดขอบเขต ชื่อพื้นที่ จำนวนรายชื่อ และบริบทพื้นที่ข้างเคียง
- `hooks/use-map-camera.ts`: ซูม เลื่อน สองนิ้ว และการเคลื่อนกล้อง
- `hooks/use-visible-layers.ts`: เลือกขอบเขตตามระดับซูม โหลดเฉพาะจังหวัดที่มองเห็น และแสดงตำบลเมื่อเลือกอำเภอ
- `data/customer-counts.ts`: อ่านยอดและแยกค่าที่ขาดหายจากค่าศูนย์

ไฟล์ทั้งหมดอยู่ใต้ `src/features/customer-map/` และ CSS แยกที่ `src/styles/customer-map.css`

## อัปเดตไฟล์รอบถัดไป

ไม่แก้ไขไฟล์ Excel ต้นฉบับ ไม่เก็บชื่อบุคคล เบอร์โทร หรือข้อมูลลูกค้ารายบุคคลในส่วนเว็บสาธารณะ

```powershell
# ใช้ Python ที่ติดตั้ง openpyxl เพื่ออ่านข้อมูลสรุปจากรูปแบบชีตเดิม
python scripts/read-customer-workbook.py "C:/path/to/new-file.xlsx" data/customer-map/source-aggregates.json

# สร้างขอบเขตฐานก่อนนำเข้าทุกครั้ง
node scripts/prepare-customer-map.mjs 5c611f8cd92691bdc62d7492983480516b00500d
node scripts/import-customer-map.mjs

# ตรวจความสัมพันธ์ของพื้นที่และยอดรวม
npx tsx --test tests/customer-map/data.test.ts
npm run typecheck
```

สคริปต์อ่านวันที่จากหัวชีต ตรวจค่าจำนวนที่เป็นจำนวนเต็มไม่ติดลบ ตรวจแถวซ้ำ และตรวจยอดรายจังหวัดกับยอดทั้งทะเบียนก่อนบันทึก หากโครงสร้างหรือจำนวนพื้นที่เปลี่ยนจากรุ่นนี้ ให้ตรวจและปรับสัญญาข้อมูลก่อนนำเข้า ไม่เดาหรือทิ้งแถวที่จับคู่ไม่ได้
